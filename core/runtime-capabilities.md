# 运行环境能力契约

Skill 不假设自己一定拥有本地文件、脚本、网页或 PDF 能力。启动时先检查或询问以下能力，并将结果写入本次运行的 `runtime` 状态：

| 能力 | 值 | 用途 |
|---|---|---|
| `read_local_files` | `yes/no/unknown` | 读取本地档案、训练日志和 PDF |
| `write_local_files` | `yes/no/unknown` | 保存 Markdown 档案、计划和修订记录 |
| `web_access` | `yes/no/unknown` | 搜索网页和平台官方搜索页 |
| `file_upload` | `yes/no/unknown` | 接收 PDF、CSV、表格、图片或日志 |
| `script_execution` | `yes/no/unknown` | 运行依赖预检、视频工具和 PDF 脚本 |
| `pdf_generation` | `yes/no/unknown` | 生成一页周计划 PDF |
| `persistent_chat_context` | `yes/no/unknown` | 在当前会话继续使用档案快照 |

## 自动检测顺序

优先使用当前客户端已经提供的工具能力和工作区信息判断；不要把“能输出代码”误判成“能写入本地文件”。在本地环境中可以用 `scripts/check-runtime-capabilities.sh` 进行基础检查。

如果平台没有能力探测接口，只显示一次以下兜底问题：

```text
为了选择合适的工作方式，请确认当前环境：

A. 本地工作环境，可以读取和保存文件
B. 手机聊天框，可以上传文件或访问网页
C. 普通聊天框，只能使用当前对话中的内容
```

用户选择后仍要把未确认的能力标为 `unknown`，不要承诺平台无法提供的文件写入或安装操作。

## 三种运行模式

### 本地完整模式

进入条件：`read_local_files=yes`、`write_local_files=yes`，并可选拥有脚本或 PDF 能力。

- 读取并更新 `fitness-data/profile.md`。
- 计划写入 `fitness-data/plans/`，修订写入 `fitness-data/revisions/`。
- 可运行依赖预检和 PDF 导出。
- 视频搜索可使用本地工具，也可降级为官方搜索页。

### 聊天增强模式

进入条件：可以读取 Skill/GitHub、接收用户上传或网页链接，但不能可靠写入用户电脑。

- 在当前聊天输出档案和计划 Markdown。
- 生成一个可复制的“个人档案快照”，供下一次聊天恢复。
- 可根据网页访问能力提供三平台链接；不能代替用户安装手机工具或完成扫码登录。
- PDF 只在客户端明确提供生成能力时创建，否则输出可打印的 Markdown 周表。

### 纯聊天模式

进入条件：只能处理当前对话文字。

- 仍执行相同的询问、档案确认、安全筛查和计划逻辑。
- 要求用户粘贴档案快照、计划或训练记录后再恢复历史。
- 资源层只输出可复制的官方搜索链接和关键词，不声称已经检索到具体视频。

## 能力边界

无法自动识别时，只问一次环境问题；进入模式后不要反复询问相同能力。平台没有长期存储时，档案快照就是恢复机制。平台没有浏览器或搜索能力时，不能伪造视频标题、作者、点赞数或链接。
