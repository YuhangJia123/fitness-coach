# 交互式选择题协议

本 skill 以选择题作为默认交互方式。每次只展示当前阶段必要的问题，使用编号或字母选项；允许多选时明确写“可多选”。用户可以直接补充文字，补充内容按事实记录。不要一次发送完整长问卷。

如果运行环境提供结构化的用户提问组件，优先用它呈现非敏感的单选或多选题；没有组件时，用相同选项在消息中提问。身高、体重、照片、伤病和饮食等个人资料让用户自行输入或导入，不把敏感内容放进不适合的选择题组件。

## 通用规则

1. 进入 `create` 或 `adjust` 后，先问资源需求和当前模式入口；随后再问“选择哪种资料方式”。选项应包含 `导入`、`照片/截图`、`文字` 和 `AI 问询` 中与当前任务有关的入口。
2. 用户选择多种来源时，按用户选择的顺序处理，合并重复字段，并保留每条信息的来源、日期和置信度。
3. 用户选择 `AI 问询` 时，一次只问一个高影响问题；用户选择导入时，先等待文件或内容，再只询问导入后仍缺失的字段。
4. 选择题不能代替安全筛查。安全问题使用“是 / 否 / 不确定”三项；回答“是”或“不确定”时先处理安全边界。
5. 每个阶段结束后，用一行摘要让用户确认“确认 / 修改”，再进入下一阶段或写入档案。

总体计划或修订计划完成后，再询问是否需要本周便携 PDF；PDF 依赖缺失时使用 [weekly-pdf-export.md](weekly-pdf-export.md) 的安装、临时环境或 Markdown 选项，不把 PDF 生成混入训练计划本身。

在总体计划或修订计划已经写入文件后，聊天中输出 [post-plan-closing.md](post-plan-closing.md) 规定的祝福、免责声明和开发者 QQ。不要把这段结语写进个人档案或计划 Markdown；建档、资料导入和普通问答阶段不显示联系方式。

档案摘要确认后、周期设计前，必须询问计划依据是否需要补充：

```text
本计划默认根据以下两份 PDF 和你的个人档案生成：
1. 《力量训练原理：用七大核心原理科学提升力量》（美）迈克·伊瑟泰尔
2. 《力量举计划设计手册》第 3 版

是否需要补充其他训练依据？
A. 不需要
B. 需要（你可以上传 PDF、粘贴网页或文章链接，或描述希望参考的内容；skill 会自动参考）
```

选择 B 后，用户可以直接上传 PDF、粘贴网页或文章链接，或描述希望参考的内容；skill 自动识别资料类型，先提取或整理，再和两份基础 PDF 的摘要合并。资料没有实际读取或核实前，不得声称已使用。详细规则见 [evidence-intake.md](evidence-intake.md)。

## 建立计划 `create`

### 入口

```text
请选择本次要建立的训练目标（可选 1 个主目标，最多 2 个次目标）：
1. 身体结构与功能优化
2. 力量举
3. 部位专攻
4. 增肌
5. 减脂塑形
6. 先让我通过 AI 问询再决定
```

若用户选择多个目标，继续给出主目标排序题，不把所有目标默认当作最高优先级。若选择“先让我通过 AI 问询再决定”，先完成目标决策问询，再进入个人资料来源题；后续选择 AI 资料问询时只补目标决策中尚未回答的档案字段。

### 个人资料来源

```text
你想用什么方式建立个人档案？（可多选）
A. 直接输入文字
B. 导入文件：CSV / 表格 / 健身 App / 历史训练日志 / 饮食记录
C. 上传训练截图
D. 上传身体照片
E. 由 AI 逐项问询
F. 混合使用以上方式
```

选择截图或照片时，先询问：

```text
你允许从图片中记录哪些内容？（可多选）
1. 训练动作、组数、次数和重量
2. 体重、腰围或体脂估计
3. 可见的训练环境或器械
4. 不从图片提取个人身体信息
5. 只提取我在文字中指定的区域
```

不对体态、体脂或伤病作诊断。选择文件或图片后，先读取再询问缺失项。选择 `E` 或 `F` 时，只问导入资料中仍缺失或未确认的字段，不重复询问已有字段。

如果用户选择 AI 问询，身高和体重使用阶段选项，并提供精确输入：

```text
你的身高是？
1. 140-159 cm
2. 160-169 cm
3. 170-179 cm
4. 180-189 cm
5. 190 cm 以上
6. 精确输入（推荐，能更准确地生成计划）
7. 不提供

你的体重是？
1. 50 kg 以下
2. 50-59 kg
3. 60-69 kg
4. 70-79 kg
5. 80-89 kg
6. 90 kg 以上
7. 精确输入（推荐，能更准确地生成计划）
8. 不提供
```

年龄默认使用年龄段，不要求精确年龄；身高和体重优先推荐精确输入，因为它们会直接影响训练剂量、体重趋势和负荷估算。性别选项为：`1. 男  2. 女  3. 不愿回答`，只作为可选背景信息。

安全筛查必须使用：`1. 否，没有上述情况  2. 是，存在一种或多种  3. 不确定，需要进一步说明`。选择 2 或 3 时停止高强度计划生成并进入安全处理。

### 训练条件

先用选择题收集高影响约束：

```text
每周可训练几天？
1. 1 天  2. 2 天  3. 3 天  4. 4 天  5. 5 天  6. 6 天  7. 不固定，需要 AI 问询

每次训练可用多久？
1. 30 分钟以内  2. 30-45 分钟  3. 45-60 分钟
4. 60-90 分钟  5. 90 分钟以上  6. 不固定，需要 AI 问询

训练场地和器械？（可多选）
1. 完整健身房  2. 基础健身房  3. 居家：哑铃/壶铃
4. 居家：弹力带  5. 居家：徒手  6. 其他/需要 AI 问询

当前是否已有计划？
1. 没有  2. 有，直接输入  3. 有，导入截图/文件/日志  4. 不确定，需要 AI 问询
```

用户只提供每周训练天数时，先由 AI 根据训练频率、睡眠、疲劳、动作负荷和肌群恢复自动安排训练日期，再询问“接受自动安排 / 自己修改”。用户可以覆盖自动安排。

### 重点部位与偏好

```text
是否有想优先改善的部位或动作？
1. 没有，均衡发展
2. 上半身
3. 胸部
4. 背部
5. 肩部
6. 手臂
7. 下半身
8. 臀腿
9. 核心
10. 指定动作或其他部位（请补充）
11. 由 AI 问询
```

### 视频资源

进入 `create` 或 `adjust` 后先使用以下选择题确认资源需求；计划中的每一个动作确定后都执行对应搜索。默认选项仍是三平台搜索：

```text
是否为计划中的每个动作搜索动作资源？
1. 需要：B 站 + 抖音 + 小红书（默认）
2. 只搜索 B 站
3. 只搜索抖音和小红书
4. 不需要视频资源
5. 先生成计划，稍后再搜索
```

若选择 1-3，等计划中的每个动作确定后先运行依赖预检，再根据预检结果询问是否安装。抖音和小红书登录由用户在本地扫码完成。

安装或搜索前先运行依赖预检。若有缺失依赖，给出以下选择题；核心计划生成不因缺少 Python 或视频工具而中断：

```text
检测到可选视频工具依赖缺失，怎么继续？
1. 不安装，直接使用官方搜索页和关键词（不需要 Python）
2. 安装到用户目录
3. 建立临时环境，搜索结束后清理
4. 跳过视频资源
```

选择 2 或 3 即表示同意安装可选检索工具；如果 Python 不存在，再单独询问是否允许安装 Python 3.10+。选择 3 使用临时目录，不写入项目档案中的认证材料。详细检查项见 [dependency-preflight.md](dependency-preflight.md)。

## 修正计划 `adjust`

先读取已有档案和当前计划；如果没有旧计划，直接转入 `create`，不先收集修正反馈。已有旧计划时，再用选择题识别变化：

```text
这次哪些内容发生了变化？（可多选）
1. 每周训练天数或训练时间
2. 健身房/居家器械
3. 目标或重点部位
4. 当前计划完成情况
5. 疲劳、睡眠或工作压力
6. 疼痛、异常症状或医生意见
7. 体重、腰围、饮食或恢复
8. 没有变化，只提交本周训练反馈
9. 需要 AI 逐项问询
```

```text
请选择本周训练反馈方式：（可多选）
A. 直接输入文字
B. 导入训练截图
C. 导入 CSV / App 记录
D. 导入历史训练日志
E. 导入睡眠、体重或饮食记录
F. AI 逐项问询
G. 混合使用以上方式
```

如果选择 `F` 或 `G`，再给出反馈字段选择题：

```text
本次想反馈哪些方面？（可多选）
1. 训练完成率和实际训练量
2. 疲劳 1-10
3. 计划 RPE 与实际 RPE 差异
4. 睡眠时长和质量
5. 酸痛位置和持续时间
6. 动作质量、失败组或异常反应
7. 体重/腰围、食欲和工作压力
8. 疼痛、麻木、头晕、胸闷或医生意见
9. 全部由 AI 逐项问询
```

反馈问询按用户选择的字段进行；没有选择的字段不主动追问。第 8 项必须继续给出 `1. 否  2. 是  3. 不确定`，选择“是”或“不确定”立即转安全处理。若变化题和资料题同时选择 AI，只进入一次 AI 问询流程，合并两者的缺失字段。

```text
希望本次调整范围是？
1. 只调整下一次训练
2. 调整本周小周期
3. 调整当前中周期
4. 重新设计完整周期
5. 由 AI 根据反馈决定最小必要调整
```

若入口资源题选择了“先生成计划，稍后再搜索”，在调整后的动作确定后才询问：

```text
现在是否搜索调整后动作的视频资源？
1. 是，按默认三平台搜索
2. 是，只搜索指定平台
3. 否，只更新训练计划
```

如果入口资源题已经选择了需要或不需要，直接执行或跳过，不再次询问。

## 其他模块

- 动作有多个可行替代时，先给出动作候选题，让用户选择保留动作、替代动作或 AI 推荐；不静默替换。
- 复盘或数据导入时，先询问资料来源，再询问用户要看训练完成、疲劳恢复、动作进步、体重趋势或全部摘要。
- 安全筛查固定给出：`1. 否  2. 是  3. 不确定`。选择 2 或 3 时停止高强度计划生成并建议专业评估。
- 不要用选择题收集 Cookie、Token、密码或验证码；登录只引导用户在本地工具或浏览器中完成。
