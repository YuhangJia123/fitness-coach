# 计划依据确认与补充资料

## 默认基础依据

每次创建或修正计划时，默认把以下两份用户提供的 PDF 作为基础参考：

1. 《力量训练原理：用七大核心原理科学提升力量》（美）迈克·伊瑟泰尔
2. 《力量举计划设计手册》第 3 版

对应文件名：

- `力量训练原理 用七大核心原理科学提升力量 ((美）迈克·伊瑟泰尔.pdf`
- `力量举计划设计手册_第3版_电子版.pdf`

如果文件在当前环境不可读，明确说明未能读取，不凭书名补写内容；可以继续使用已提取的项目参考摘要，但要标记限制。

## 确认问题

在个人档案摘要确认后、周期设计前询问：

```text
本计划默认根据以下两份 PDF 和你的个人档案生成：
1. 《力量训练原理：用七大核心原理科学提升力量》（美）迈克·伊瑟泰尔
2. 《力量举计划设计手册》第 3 版

是否需要补充其他训练依据？
A. 不需要
B. 需要（你可以上传 PDF、粘贴网页或文章链接，或描述希望参考的内容；skill 会自动参考）
```

选择 A 后直接进入计划设计。选择 B 后，直接接收用户提供的 PDF、网页或文章链接，或文字描述；skill 自动识别资料类型并执行提取、总结和来源记录，不需要用户再次选择类型。

## 补充资料处理

对每份新资料建立一条来源记录：标题、作者/机构、文件路径或 URL、获取日期、可读取范围、关键原则、适用人群、证据强度，以及与两份基础 PDF 的一致或冲突之处。

PDF 使用可用的 PDF 读取工具提取文本；链接读取公开页面或用户提供的内容；文字描述按“用户提出的依据/偏好”记录，不能伪装成已验证研究结论。若资料之间冲突，展示冲突并询问用户采用哪一项，不静默覆盖基础依据。

计划设计时使用“基础 PDF 提取摘要 + 已确认的补充依据摘要 + 个人档案 + 当前训练反馈”的合并依据包，并在计划的“假设与数据来源”中列出。补充依据只影响它实际支持的部分，不得覆盖安全边界或把一般建议变成医学处方。
