# 运行前依赖预检

本 skill 的核心能力不依赖 Python：个人 Markdown 档案、训练计划、周期设计、反馈修正和三大平台官方搜索页/关键词都可以直接运行。Python、第三方包和浏览器自动化只属于可选的视频检索增强层。

在本地客户端进入流程前，先运行基础能力探测：

```bash
fitness-coach/scripts/check-runtime-capabilities.sh fitness-coach
```

它只报告当前进程能够确认的本地事实；上传、网页搜索和聊天持久化仍由平台适配层决定，不能用这个脚本替代手机聊天框的能力判断。

## 预检顺序

进入 `create` 或 `adjust` 后，在执行视频工具或平台搜索前运行：

```bash
fitness-coach/scripts/check-video-tools.sh
```

预检至少检查：

- 核心运行环境和项目目录是否可读写；
- Python 3.10+ 是否存在（只在选择 Python 工具时需要）；
- Python 的 `venv` 和 `pip` 能力是否可用（只在选择安装 Python 工具时需要）；
- PDF 导出所需的 `reportlab` 和页面渲染器是否可用（只在选择 PDF 时需要）；
- `bili`、`dy` 和小红书本地工具是否存在；
- 抖音 Playwright/Chromium 是否可用；
- `curl` 和系统浏览器是否可用。

预检是信息步骤。缺少可选依赖不阻止建档或生成计划。

## 依赖缺失时的选择题

```text
检测到视频检索工具或运行依赖缺失，接下来怎么做？（可多选）
1. 不安装，直接使用三大平台官方搜索页和关键词（推荐，完全不需要 Python）
2. 安装到用户目录，供以后重复使用
3. 建立临时环境，只在本次搜索中使用
4. 跳过视频资源，只生成训练计划
```

只有选择 2 或 3 时才安装可选工具。选择 2 使用默认目录 `~/.local/share/fitness-coach/video-tools`；选择 3 使用临时目录，例如：

```bash
fitness-coach/scripts/install-video-tools.sh --all --temporary
```

搜索完成后删除临时目录；不把登录材料写入项目档案。若 Python 不存在，选择 2 或 3 时先询问是否允许安装 Python 3.10+；用户不允许则回退到官方搜索页。

## 各路径的实际含义

| 选择 | 是否需要 Python | 结果 |
|---|---:|---|
| 官方搜索页/关键词 | 否 | 输出三平台官方搜索链接和可复制关键词 |
| 用户目录工具 | B 站、抖音需要；小红书发行版通常不需要 | 安装可复用工具并记录版本状态 |
| 临时环境 | B 站、抖音需要；小红书发行版通常不需要 | 本次使用后清理，不污染全局环境 |
| 跳过视频资源 | 否 | 只输出档案和训练计划 |

PDF 导出是独立的可选功能。如果 `pdf_reportlab`、`pdf_renderer` 或 `pdf_cjk_font` 缺失，询问是否安装 PDF 依赖、用临时 Python 环境生成，或只输出 Markdown 周摘要。

安装工具前仍需用户明确同意。安装脚本不执行登录、不读取 Cookie、Token、密码或验证码；抖音和小红书的扫码登录由用户自行完成。
