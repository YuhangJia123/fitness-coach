# Fitness Coach

跨平台个人健身计划与调整 Skill。它以个人训练档案为事实层，以训练计划为推理层，以训练反馈为修正层，帮助成年人建立和维护可执行的训练系统。

适用目标包括：

- 身体结构与功能优化
- 力量举
- 部位专攻
- 增肌
- 减脂塑形

它支持两种主要任务：

- **建立计划**：询问目标、个人资料、训练条件、恢复状态和重点部位，生成个人档案与周期计划。
- **修正计划**：读取已有档案和计划，结合训练完成情况、疲劳、睡眠、疼痛和器械变化，生成带版本号的修订计划。

## 能做什么

### 个人档案

资料可以来自：

- 文字输入
- 训练截图或身体数据截图
- CSV、表格或健身 App 导出
- 历史训练日志
- 饮食、体重、腰围和恢复记录
- AI 逐项问询

Skill 默认使用选择题推进流程，每次只问当前最有影响的问题。身高和体重推荐精确输入；性别选项为男、女和不愿回答；运动安全筛查使用“否 / 是 / 不确定”三选题。

### 周期计划

计划包含：

- 大周期（宏周期）
- 中周期（mesocycle）
- 小周期（microcycle）
- 热身、主项、辅助动作和替代动作
- 组数、次数或时长、RPE/RIR、休息时间
- 进阶方式、减量条件和下次反馈问题

安排动作时会检查恢复间隔：同一重点部位的高强度训练尽量间隔 48 小时；连续训练日错开重点部位；休息两天后才安排较高强度主项；睡眠较差或疲劳升高时降低高强度下肢负荷。

### 动作资源

计划中的每一个动作都可以搜索：

- 哔哩哔哩
- 抖音
- 小红书

默认优先搜索以下创作者：

1. 谭成义
2. 凯胜王
3. 王一涵

随后再考虑其他可核验的专业或头部创作者，并用收藏、点赞、播放等公开互动数据作为排序参考。检索不到具体结果时，输出官方搜索页和可复制关键词，不编造标题、作者或链接。

### 训练依据

默认依据是：

- 《力量训练原理：用七大核心原理科学提升力量》（美）迈克·伊瑟泰尔
- 《力量举计划设计手册》第 3 版

建立档案后会询问是否补充其他依据。选择“需要”后，可以上传 PDF、粘贴网页或文章链接，或直接描述希望参考的内容；Skill 会先提取和总结，再与默认依据合并。

### 周计划文档

总体计划完成后，会询问是否生成本周便携表格。支持的本地环境可以生成一页 A4 横向 PDF；手机聊天框或普通聊天框则输出可复制的 Markdown 周表。未来说“生成第 N 周计划”或“导出某一周”时，会从当前 Markdown 计划中截取，不重新设计训练剂量。

## 使用流程

每次启动都会先判断当前环境：

- **本地完整模式**：可以读写文件，可选运行脚本和生成 PDF。
- **聊天增强模式**：可以读取 GitHub、网页或用户上传文件，但不能可靠写入用户电脑。
- **纯聊天模式**：只能处理当前对话内容。

无法自动判断时，只会询问一次：

```text
为了选择合适的工作方式，请确认当前环境：

A. 本地工作环境，可以读取和保存文件
B. 手机聊天框，可以上传文件或访问网页
C. 普通聊天框，只能使用当前对话中的内容
```

随后按以下顺序工作：

1. 选择“建立计划”或“修正计划”。
2. 选择是否为计划中的每个动作搜索三大平台资源。
3. 选择资料来源：文字、文件/表格、截图/照片或 AI 问询。
4. 完成安全筛查和个人资料采集。
5. 输出个人档案摘要，用户选择“确认 / 修改”。
6. 询问是否补充训练依据。
7. 生成或修正大周期、中周期、小周期。
8. 搜索每个动作的三平台资源，或输出官方搜索链接和关键词。
9. 询问是否生成本周便携文档。
10. 在计划创建或修正完成后的聊天结语中显示开发者 QQ：`3193914069`。

联系方式不会在建档、资料导入、动作问答或普通训练反馈阶段显示；Skill 不收集或显示使用者的联系方式，也不使用开发者微信。

## 各系统使用方法

### Codex 本地环境

Codex 支持本地 Skill、项目文件和脚本。将仓库放进 Codex 的 Skill 目录：

```bash
git clone https://github.com/YuhangJia123/fitness-coach.git ~/.codex/skills/fitness-coach
```

然后在 Codex 中直接说：

```text
使用 fitness-coach，建立一个新的力量举计划。
```

本地模式会使用：

- `fitness-data/profile.md`：个人档案
- `fitness-data/plans/`：计划版本
- `fitness-data/revisions/`：修订版本
- `fitness-data/exports/`：周计划 PDF

核心流程不需要 Python。运行视频工具或 PDF 导出前，Skill 会先检查依赖并让你选择官方搜索页、用户目录安装、临时环境或跳过。

### Claude Code

Claude Code 不会自动把 Codex 的 `SKILL.md` 当作内置 Skill。将仓库放进项目后，在项目 `CLAUDE.md` 中说明它是本项目的训练计划工作流，并让 Claude 读取：

```text
请读取并遵循 fitness-coach/SKILL.md。
同时按当前任务读取 fitness-coach/core/、fitness-coach/adapters/ 和相关 references/。
```

使用示例：

```text
按照 fitness-coach 建立一份 8-12 周的力量举基础计划。
```

在 Claude Code 中可使用本地 Markdown 和脚本；如果当前项目没有写入权限，改用聊天增强模式输出档案快照和计划。

### DeepSeek 手机聊天框

手机端不能假设能读取你的电脑目录，也不能替你安装本地工具。先打开 [移动端启动提示词](adapters/mobile-bootstrap-prompt.md)，将其中的 `<YOUR_GITHUB_REPOSITORY_URL>` 替换为本仓库地址，然后粘贴到 DeepSeek 聊天框。

也可以直接粘贴以下仓库地址：

```text
https://github.com/YuhangJia123/fitness-coach
```

手机端会在当前聊天中输出：

- 个人档案 Markdown 快照
- 大周期、中周期、小周期计划
- 每周训练表
- 每个动作的三平台链接或关键词
- 计划版本和调整记录

换新对话时，把最近一次个人档案快照粘贴回去即可恢复。

### 豆包手机聊天框

使用方法与 DeepSeek 相同：让豆包读取本仓库的 `SKILL.md`、`core/`、`adapters/doubao-mobile.md` 和当前任务相关的 `references/`，或者直接粘贴 [移动端启动提示词](adapters/mobile-bootstrap-prompt.md)。

豆包手机端默认在聊天中输出 Markdown，不假设能写入电脑文件。需要 PDF 时，先输出周计划 Markdown；有明确文件生成能力时再生成 PDF。

### 普通聊天框

如果聊天框不能访问 GitHub，先粘贴以下内容：

```text
请按照 fitness-coach 的工作流执行：先询问建立计划或修正计划，再进行安全筛查和选择题式资料采集，生成个人档案并让我确认，然后生成大周期、中周期、小周期和每个动作的三平台搜索关键词。所有内容直接输出在当前聊天中，不要假装写入本地文件。
```

普通聊天框没有历史存储时，请保存并在下一次粘贴个人档案快照。

## 依赖与登录

核心档案、训练计划和官方搜索页不需要 Python。视频工具和 PDF 导出是可选功能。

计划中的动作资源默认先使用官方搜索页兼容模式。若用户同意安装可选工具，Skill 才会运行：

```bash
scripts/check-video-tools.sh
scripts/install-video-tools.sh --all
```

也可以使用临时环境：

```bash
scripts/install-video-tools.sh --all --temporary
```

哔哩哔哩公开关键词搜索通常不需要登录；抖音和小红书搜索可能需要用户在本地扫码登录。Skill 不收集 Cookie、Token、密码或验证码。

## 安全边界

这是一般训练信息工具，不是医疗诊断、康复处方或面对面教练。出现运动时胸痛、晕厥、异常气短、进行性疼痛、麻木无力、近期手术、孕期、已知心肺或代谢疾病、医生限制或不确定情况时，Skill 会停止高强度计划流程并建议寻求专业意见。

如果训练中觉得“眼睛会了但是身体没会”，或出现疼痛和不适，应暂停相关动作，记录情况并及时反馈。
