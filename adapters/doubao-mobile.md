# 豆包手机聊天框适配

适用于不能直接读写用户电脑目录、但可以在当前聊天中处理文字、上传内容或网页链接的场景。

## 启动

1. 读取 GitHub 中的 `SKILL.md`、`core/`、相关 `references/` 和本适配说明。
2. 将 `runtime` 设为 `chat_enhanced`，除非平台明确提供本地文件写入接口。
3. 如果没有历史档案，要求用户粘贴个人档案快照或重新开始问询。

## 输出

- 直接在聊天中输出档案、周期计划、动作资源表和调整记录。
- 每次修改增加版本号，保留上一版本的简短变化摘要。
- 每个计划动作都给出三大平台的搜索结果，或官方搜索页和可复制关键词。
- 需要周计划时输出一页式 Markdown 表格；只有客户端明确提供 PDF 能力时才生成 PDF。

## 能力限制

- 不能替用户安装本地依赖或修改电脑项目目录。
- 不能代替用户完成抖音和小红书登录。
- 没有实际网页检索结果时，不编造标题、作者、互动数或 URL。

计划创建或修正完成后显示开发者 QQ `3193914069`。不要询问或显示使用者的联系方式，也不要显示开发者微信；其他阶段不显示联系方式。
