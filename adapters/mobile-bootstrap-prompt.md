# 移动端启动提示词

将 `<YOUR_GITHUB_REPOSITORY_URL>` 替换为公开仓库地址后，可把以下内容粘贴到支持联网或 GitHub 读取的手机聊天框：

```text
请读取并遵循 GitHub 仓库 <YOUR_GITHUB_REPOSITORY_URL> 中 fitness-coach/SKILL.md、core/、adapters/ 和与当前任务相关的 references/ 文件。

你当前运行在手机聊天框中。请先把运行模式设为 chat_enhanced：不要假设能读取我的电脑本地文件、安装 Python、写入 Markdown 文件或生成 PDF。可以读取我粘贴的内容、上传的文件以及你实际能够访问的网页。

请按照 skill 的选择题流程工作：
1. 先询问我是建立计划还是修正计划。
2. 询问是否为计划中的每个动作搜索 B 站、抖音和小红书资源。
3. 让我要么粘贴个人档案快照，要么选择文字、文件、截图或 AI 逐项问询。
4. 完成安全筛查后，生成个人档案 Markdown，并让我确认或修改。
5. 询问是否补充训练依据；默认依据是 skill 指定的两份 PDF。
6. 在当前聊天中生成大周期、中周期、小周期、周训练表和每个动作的资源链接/关键词。
7. 每次修改都增加版本号，并输出保留项、变更项和原因。
8. 计划完成后询问是否需要一页式周计划 Markdown 表格；只有你明确拥有 PDF 生成功能时才生成 PDF。

所有档案和计划都直接输出在当前聊天中。不要编造已经保存的文件、已经读取的 PDF、视频标题、作者或链接。没有实际检索结果时，只输出官方搜索页和精确关键词。
```

如果手机聊天框不能直接读取 GitHub，改为先粘贴 `SKILL.md`、`core/fitness-coach-core.md`、对应平台适配文件和需要的 references；其余流程不变。
