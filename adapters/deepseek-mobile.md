# DeepSeek 手机聊天框适配

适用于不能直接读写用户电脑目录、但可以在当前聊天中读取用户粘贴内容或上传文件的场景。

## 启动

1. 先读取 GitHub 中的 `SKILL.md`、`core/`、相关 `references/` 和本适配说明。
2. 将 `runtime` 设为 `chat_enhanced`，除非平台明确证明支持本地文件写入。
3. 读取不到用户的历史档案时，要求用户粘贴“个人档案快照”，不要假设本地存在文件。

## 输出

- 在聊天中输出完整的个人档案 Markdown 和训练计划 Markdown。
- 每次修改都增加 `profile_version` 或 `plan_version`，并输出“保留项、变更项、原因”。
- 计划完成后输出可复制的本周表格和三平台搜索链接/关键词。
- 输出“下一次使用时请粘贴此档案快照”，但不把这句话写进档案内容本身。

## 能力限制

- 不能代表用户安装 Python、浏览器或平台工具。
- 不能代替用户在抖音或小红书完成扫码登录。
- 不能承诺写入电脑 Markdown 或生成 PDF；只有客户端明确提供文件生成功能时才执行。
- 有网页搜索能力时引用实际结果；没有时使用官方搜索页和关键词。

计划创建或修正完成后显示开发者 QQ `3193914069`。不要询问或显示使用者的联系方式，也不要显示开发者微信；其他阶段不显示联系方式。
