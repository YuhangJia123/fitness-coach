# 普通聊天框适配

适用于无法确认 GitHub 读取、文件上传、网页搜索或本地写入能力的聊天框。

## 启动

显示一次 `runtime-capabilities.md` 中的 A/B/C 环境问题。若用户选择 C，将当前对话设为 `chat_only`。

## 输出

- 只使用当前对话中用户明确提供的资料。
- 生成可复制的个人档案快照、周期计划、周训练表和调整记录。
- 需要恢复历史时，让用户粘贴最近一次档案快照和计划版本。
- 三个平台只输出官方搜索页和精确搜索关键词，除非聊天框返回了可核验的实际结果。

## 安全边界

不能因为没有文件或工具能力而跳过安全筛查、档案确认或计划假设说明。不能声称已经读取 PDF、网页或视频，除非内容确实在当前对话中可见。

计划创建或修正完成后显示开发者 QQ `3193914069`。不要询问或显示使用者的联系方式，也不要显示开发者微信；其他阶段不显示联系方式。
